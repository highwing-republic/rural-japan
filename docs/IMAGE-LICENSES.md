## Modifications and attribution

- Original JPEGs are resized to 1920 px and 800 px wide and converted to WebP. The original aspect ratio is retained in the saved assets.
- Page layouts may display cropped versions through CSS `object-fit: cover`. No objects were added, removed, or generated.
- Use the original title, author, source link, license and modifications supplied by `src/data/photos.json` when presenting photo credits. The shared credit page must remain reachable wherever the photos appear.
- A suitable attribution is: “Neba River Tsukize ac (1) — Asturio Cantabrio / Wikimedia Commons / CC BY-SA 4.0. Resized, converted to WebP and cropped for layout.” Link the source and license as recorded in the manifest.
- `docs/image-evidence.json` retains the Commons API response with source URLs, original dimensions, descriptions, artist attribution, dates and license metadata. The images were also visually inspected to check the described subjects.
